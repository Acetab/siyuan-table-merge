# 表格合并

[English](README.md)

把人工复核完成的 Markdown 表格，安全合并进思源中明确选中的已有表格。

![表格合并功能预览](preview.png)

> 说明：预览图为 AI 辅助制作的功能示意图，与插件实际界面存在差异，请以
> 实际运行效果为准。

## 为什么做这个插件

思源的标准表格使用 Markdown 表格语法保存。我的日常需求是：让 AI 定期整理和
清洗一批资料，输出 Markdown 表格，再把这些结果增量合并到已有的思源文档中。

直接手工复制时，需要自己判断重复链接、同名不同链接、来源变化和提取码变化；
表格较多时还容易选错“课程”“真题”等使用相同表头的分区。思源数据库虽然也能
添加链接，但对于这类由 AI 生成、需要保留 Markdown 超链接写法、并且希望方便
复制和迁移的资料，标准 Markdown 表格更符合我的使用习惯。

因此，这个插件只解决最后一步：**把已经整理和人工复核过的 Markdown 表格，
可预览、可选择、可备份地合并到现有表格。**

## 主要功能

- 明确选择一个思源表格块作为目标，不猜文档或目标位置；
- 在目标表格中打开插件并粘贴，立即按源表头分列显示可勾选的数据行；
- 默认把粘贴内容第一行作为表头，并一键全选第 2 行及以后，也可逐行取消；
- 第一行本身是数据时，可关闭“第一行作为表头”并把它纳入选择；
- 源、目标表头一致时跳过映射并自动预览；同名表头仅顺序不同时按名称重排；
- 支持粘贴完整 Markdown、只有数据行的 Markdown/Tab 文本，也支持读取本地 `.md` 文件；
- 无表头数据行必须逐列核对目标表头并勾选确认，不会因列数相同而自动通过；
- 直接从思源复制数据行到插件时，会从剪贴板富文本恢复标准链接及思源链接；
- 从思源富文本剪贴板恢复标准 Markdown 超链接，避免多选复制后链接退化为文字；
- 多表文件会显示文件名、Markdown 标题路径、行号、表头和前两行；
- 表头不匹配的表格不可选择，同表头的不同分区仍需人工勾选；
- 区分新增、完全重复、同名/疑似同名不同链接和同链接内容冲突；
- 百度网盘、夸克网盘按平台和分享 ID 识别，提取码变化不会制造重复行；
- 同名不同链接及百度/夸克镜像全部保留；
- 冲突可选择保留原行、使用输入行，或保留原行并只合并“来源”；
- 写入前重新读取目标并备份，写入后验证表头、行数、顺序和链接集合；
- 不上传表格内容，不调用外部 AI 或链接检测服务。

## 快速搬行（推荐）

1. 在思源中明确选中目标表格，点击顶栏表格合并图标。
2. 在原有输入框粘贴复制的表格内容。插件会在同一窗口立即按列展示数据行。
3. 默认勾选“第一行作为表头”，并全选第 2 行及以后；可以使用“全选全部数据行”
   一键全选/清空，也可以逐行取消。若复制内容不含表头，关闭第一项即可。
4. 点击“使用所选行生成预览”。表头完全一致时直接预览；相同名称仅顺序不同时
   自动重排；只有表头确实不同时才要求人工映射。
5. 查看新增、重复、同名提示和冲突，选择处理方式后最终写入。

首次使用请在可丢弃文档中复制一份表格测试，不要直接操作唯一副本。

## 完整 Markdown 与本地文件

同一个窗口也支持完整 Markdown 表格、竖线/Tab 分隔内容和本地 `.md` 文件。
多表文件仍按文件名、标题路径和表头明确选择。

## 输入与映射要求

默认情况下，粘贴内容第一行由用户明确指定为源表头，而不是依赖 Markdown 或
思源剪贴板是否把它显示为加粗。源、目标表头不匹配，或关闭“第一行作为表头”
后没有源表头时，插件会列出“源第几列、单元格示例、目标表头”映射；默认顺序
仅供参考，必须人工核对并勾选确认。映射必须一一对应，不能遗漏或重复目标列，
列数不一致时也会阻止。直接从思源表格复制并粘贴时，插件优先读取剪贴板中的
HTML 富文本，将标准 `<a>` 和思源 `data-href` 链接恢复为 Markdown 超链接。
若剪贴板来源本身没有提供链接地址，则插件无法从普通文字反推 URL。
例如：

```markdown
| 资源 | 类型 | 平台 / 状态 | 来源 |
| --- | --- | --- | --- |
| [示例讲义](https://example.com/a) | 讲义 | 网页 / ✅ | 人工整理 |
```

一个 `.md` 文件可以包含说明文字、多个标题以及多张不同表头的表格。插件只展示
可识别的表格，并要求用户明确选择；表格以外的段落和图片不会被写入目标表格。

## 合并规则

| 情况 | 默认处理 |
| --- | --- |
| 完全相同的行 | 跳过 |
| 新链接 | 追加到表尾 |
| 同名但链接不同 | 两行都保留，并提示 |
| 百度或夸克同分享 ID、其他列不同 | 进入冲突，不自动覆盖 |
| 普通 URL 查询参数不同 | 视为不同链接 |
| 无链接行 | 仅在整行完全相同时判重 |
| 表头不一致 | 禁止选择和写入 |

名称末尾形如“（百度 · …分享ID）”或“（夸克 · …分享ID）”的装饰只会在
“疑似同名”比较时忽略。这个比较只产生提示，绝不会作为去重或覆盖依据。

## 写入安全

- 预览不会写入笔记；
- 点击最终确认后才调用思源 Kernel API；
- 写入前重新读取目标表格；如果预览后内容发生变化，会中止并要求重新预览；
- 写入前通过思源插件数据接口保存最新原表 Kramdown 备份；
- 同一表格块同时只允许一次写入；
- 写入后重新读取，并验证表头、每行内容、行数、顺序和链接集合；
- 思源表格末尾的 Kramdown IAL 属性会保留，不参与数据行判重。

## 适用范围与边界

- 目前仅支持 Windows 桌面端；
- 仅支持用户明确选中的单个标准 Markdown 表格块；
- 编辑器行选区识别属于尽力而为；识别失败时必须在插件列表中人工勾选，不会默认
  复制整张表；
- 插件不负责调用 AI、清洗聊天记录、分类内容或判断链接是否有效；
- 插件不会自动决定应合并“课程”“真题”还是其他同表头分区；
- 插件不直接编辑 `.sy` 文件，也不会把表格内容发送到外部服务。
