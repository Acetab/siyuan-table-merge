# Security

Do not post Markdown inputs, table contents, block IDs, backup files, private
links, access codes, or workspace paths in public issues.

The plugin reads and updates only the table block explicitly selected by the
user. It does not send table data to external services. For vulnerabilities
that could expose note content, select or update the wrong block, bypass the
preview, or write arbitrary files, use the repository's private
security-reporting feature.

---

# 安全说明

请勿在公开 Issue 中提交 Markdown 输入、表格内容、块 ID、备份文件、私人链接、
提取码或工作空间路径。

插件只读取并更新用户明确选中的表格块，不会把表格数据发送到外部服务。如果发现
可能泄露笔记内容、选错或写错块、绕过预览确认，或造成任意文件写入的问题，请通过
GitHub 仓库的私密安全报告功能联系维护者。
